# Develoop 0.1.0 — Initial Public Submission

Develoop packages an evidence-first GitHub delivery loop for agent hosts. Its
three primary workflows create implementation-ready issues, carry an issue
through a focused branch and validated pull request, and resolve automated
review without duplicating requests or expanding scope.

The bundle also includes a separately licensed supporting skill without making
that skill part of the Marketplace listing. Develoop is a skills-only plugin:
it runs no developer-controlled backend, creates no developer-managed account,
and collects no user data. GitHub operations use the authenticated capabilities
already provided by the user's agent host.
